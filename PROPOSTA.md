# Sistema de Gestão para Restaurantes

Sistema de Gestão para Restaurantes.

Um grande monolíto para realizar a gestão de um restaurante.

## Membros da equipe

**567680** - Victor Farias da Silva / Sistemas de informação

## Objetivo Geral

Centralizar os serviços de um restaurante.

- sistema de cardápio
- sistema de agendamento
- sistema de serviço de entrega
- sistema de clientes
- sistema de receitas

## Público-Alvo

Restaurantes.

## Impacto Esperado

Acelerar os processos de um restaurante.

## Papéis ou tipos de usuário da aplicação

- Usuário não logado e todos os usuários
- Administrador

## Principais funcionalidades da aplicação

### Usuário não logado e todos os usuários

- ver itens do cardápio

### Administrador

- criar itens do cardápio
- atualizar itens do cardápio
- remover itens do cardápio

- Imprimir cardápio
- Exportar cardápio
